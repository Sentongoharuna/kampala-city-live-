develop.uganda V235 — UGANDA LUT MIXER PRO

PURPOSE
V235 turns the existing Uganda Scene LUT system into a practical on-camera
color mixer without replacing the proven CameraX recording pipeline.

WHAT IS NEW
1. Six plain-language controls are present on EVERY LUT:
   01 GREEN  — salad, leaves, vegetation
   02 RED    — meat, signs, clothes
   03 YELLOW — banana, sun, warm lights
   04 BLUE   — sky, water, cool glass
   05 ORANGE — food, brick, warm light
   06 BROWN  — earth, wood, coffee

2. Each control runs 0–200%.
   100% = the designed LUT exactly.
   Below 100% gently reduces that color family.
   Above 100% increases that color family.
   Values auto-save independently per LUT and per camera scope.

3. The authored V231/V232 five-color Scene Palette remains available.
   V235 does not throw away the earlier work; it adds the simple six-color
   layer after it.

4. HOLD ORIGINAL remains available for instant comparison.

5. V234 navy-safe UI principles are included in V235:
   dark navy sheet, thin accent borders, bottom placement and scroll-safe lists.

SAFETY / MASTER POLICY
The original CameraX MP4 remains untouched.
The live screen grade is an operator preview.
COLOR_MASTER.mp4 is the separate final render using Media3 SingleColorLut 17^3,
the authored scene palette, the six-color V235 mixer, and H.264/AAC re-encode.
